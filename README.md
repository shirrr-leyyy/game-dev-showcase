## Cardinals — 2D Platformer

A 2D platform game built in **C/C++** by a 5-member team (**Team Optical Candy**: *Sadric, Breanne, Jerome, Shirley, Zoey*) for DigiPen's Year 1 Trimester 2 game project. Players navigate hazard-filled levels, use directional gravity arrows to shift movement, track lives (`x3`), and reach the rainbow fish goal.

### Gameplay Preview
[Watch Gameplay Trailer](./trailer/Cardinals_Trailer.mov)

### Core Gameplay & Features
- **Title & Menu Flow:** Start, Exit, Credits, and Settings screens.
- **2D Platforming & Hazards:** Spike obstacles, life tracking, and directional gravity shifts.
- **Goal Objective:** Navigate through level layouts to reach the fish collectible.

### Tech Stack & Repository
- **Language:** C / C++
- **Team Repository:** https://github.com/JeromeIsntDev/GAM150_Cardinals

## What If... — Pixel-Art Minigame Collection

A pixel-art minigame collection built in **C/C++** by **Team Ruguo** (*Felicia, Shirley, YiTing, Dylan, Jerald*), exploring everyday jobs and multi-tasking challenges—from **Wash Plates!** and **Organise Cutlery!** to **Keep Bugs from Infecting the Server!**, **Drink Coffee & Code!**, and viewing your **Earnings / Payslip**.

### Gameplay Preview
[Watch Gameplay Trailer](./trailer/WhatIf_Trailer.mp4)

### Key Features & Minigames
- **Fast-Paced Job Minigames:** Timed tasks including dishwashing, cutlery organization, server bug defense, and coding/coffee action sequences.
- **Score, Timer & Payslip Loop:** Tracks timers, scores, and shift earnings with a payslip summary and quick return flow.
- **Pixel-Art Presentation:** Custom pixel-art environments, character animations, and clear on-screen prompts.
