# Cardinals — 2D Platformer
A 2D platform game built in **C/C++** by a 5-member team (*Sadric, Breanne, Jerome, Shirley, Zoey*) for DigiPen's Year 1 Trimester 2 game project. Players navigate hazard-filled levels, use directional gravity arrows to shift movement, track lives (`x3`), and reach the rainbow fish goal.

## Gameplay Preview
https://github.com/user-attachments/assets/83e40c9f-455c-45e2-aa77-94814f6775af

## Core Gameplay & Features
* **Title & Menu Flow:** Start, Exit, Credits, and Settings screens.
* **2D Platforming & Hazards:** Spike obstacles, life tracking, and directional gravity shifts.
* **Goal Objective:** Navigate through level layouts to reach the fish collectible.
